# Article 56

Le personnel du FNS-RS comprend :
les agents contractuels du FNS-RS ;
les agents publics de I'Etat détachés du FNS-RS ;
les agents mis & la disposition du FNS-RS dans le cadre d'une coopération.
Nonobstant les dispositions de- l'article 54 ci-dessus, le FNS-RS peut s'attacher les services de toute autre catégorie de personnel recruté dans le cadre de conventions.
