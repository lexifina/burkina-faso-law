# Article 311

les permis de visite autorisent leur titulaire à pénétrer dans les aires fauniques dans un but touristique ou pour des activités à caractère commercial. Ils comportent quatre (4) catégories:
- le permis de visite pour les nationaux;
- le permis de visite pour les étrangers résidant depuis plus de six (6) mois au Burkina Faso;
- le permis de visite pour les touristes;
- le permis de visite pour la cinématographie.
