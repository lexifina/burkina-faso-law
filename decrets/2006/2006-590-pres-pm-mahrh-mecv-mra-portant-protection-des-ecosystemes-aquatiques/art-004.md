# Article 4

Les catégories d’écosystèmes aquatiques protégés sont :
- les cours d’eau permanents ou temporaires, notamment les rus, rigoles, ravines, marigots, fleuves ;
- les retenues d’eau naturelles ou artificielles, notamment les lacs de barrage, lacs de dépression, mares permanentes ou temporaires ;
- les sources ;
- les plaines inondées ;
- d’une manière générale, les zones humides.
