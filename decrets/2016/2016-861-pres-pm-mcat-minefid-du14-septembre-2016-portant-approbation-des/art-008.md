# Article 8

Dans le cadre de l’exercice de la tutelle, le Conseil d’administration du FDCT est tenu d’adopter :
1­ dans les trois (03) mois avant le début de l’exercice budgétaire:
­ les programmes d’activités ; ­ le plan annuel de l’auditeur interne ; ­ les comptes prévisionnels de recettes et de dépenses; ­ le programme de financement des investissements ; ­ les conditions d’émission des emprunts.
2­ Dans les quatre (04) mois suivant la clôture de l’exercice :
­ les états financiers et le rapport de l’auditeur interne; ­ les rapports d’activités ; ­ le rapport de gestion du Conseil d’Administration ; ­ un rapport annuel sur les problèmes rencontrés dans le fonctionnement du FDCT.
