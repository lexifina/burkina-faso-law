# Article 302

L'emploi de technicien de laboratoire médical comprend les attributions suivantes :
exécuter les tâches de laboratoire dans les hôpiiaux et autres services sanitaires ;
maintenir le matériel de laboratoire ;
préparer les réacti fa courants ;
effectuer des prélèvements en vue des ex,unens ;
exécuter les examens courants de laboratoire ;
effecmer toutes autres tâches connexes confiées par le supérieur hiérarchique dans le cadre réglementaire.
