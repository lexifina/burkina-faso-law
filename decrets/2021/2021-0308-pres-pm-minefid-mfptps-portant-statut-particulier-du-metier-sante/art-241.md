# Article 241

L'emploi de technicien supérieur de laboratoire d'élevage comprend les attributions suivantes :
réaliser les prélèvements de matières biologiques ;
réaliser les tests de diagnostic;
réaliser les tests de contrôle de laboratoire ;
réaliser les tests de contrôle de production de médicaments vétérinaires :
participer aux enquêtes épidémiologiques ;
exécuter toute autre tâche connexe confiée par le supérieur hiérarchique dans le cadre règlementaire.
