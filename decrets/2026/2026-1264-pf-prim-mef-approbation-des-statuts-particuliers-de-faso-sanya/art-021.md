# Article 21

Dans le cadre de l'exercice de la tutelle, le Conseil d'administration de Faso Sanya adopte :
dans les trois mois avant le début de l'exercice budgétaire, les programmes d'activités de l'exercice suivant, le budget prévisionnel de l'exercice suivant, le plan annuel de l'auditeur interne, le plan de passation des marchés.
dans les trois mois suivant la clôture de l'exercice, le rapport de gestion du Conseil d'administration de l'exercice précédent, le rapport annuel sur les problèmes rencontrés, le rapport d'exécution budgétaire de l'exercice précédent, les états financiers de l'exercice précédent, le rapport de l'auditeur inteme, le rapport d'exécution du plan de passation des marchés de l'exercice précédent, le rapport d'activités de l'exercice précédent.
