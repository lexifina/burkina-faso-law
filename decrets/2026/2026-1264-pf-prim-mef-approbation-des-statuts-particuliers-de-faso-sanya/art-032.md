# Article 32

Le Président du Conseil d'administration de Faso Sanya adresse aux Ministres de tutelle :
1) dans les trois mois avant le début de l'exercice :
- les comptes prévisionnels de recettes et de dépenses ;
- le programme de financement des investissements ;
- le programme de travail annuel.
2) dans les trois mois suivant la clôture de l'exercice :
- les états financiers ;
- le rapport d'activités ;
- le rapport annuel sur les problèmes rencontrés dans le fonctionnement.
