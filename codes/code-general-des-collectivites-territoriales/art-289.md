# Article 289

Le secrétaire général est nommé par le maire parmi les agents des catégories A, B ou C de l’administration générale ou agents assimilés.
Le secrétaire général peut être un agent recruté par la commune ou un agent mis à disposition ou en position de détachement par l’Etat.
