# Article 23

- Les magistrats militaires constituent un corps autonome à hiérarchie propre, dont les effectifs, le recrutement et la formation font l'objet d'un statut particulier fixé par la loi.
La hiérarchie du corps des magistrats militaires comporte:
- les magistrats militaires adjoints
- les magistrats militaires de 3° Classe
- les magistrats militaires de 2° Classe
- les magistrats militaires de 1° Classe
- les magistrats militaires généraux = Capitaines = Commandants = Lieutenant-Colonels = Colonels = Généraux.
