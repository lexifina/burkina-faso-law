# Article 118

Les infractions prévues dans le présent titre sont poursuivies devant les juridictions judiciaires de droit commun, sous réserve de la compétence des juridictions militaires dans les cas prévus par le code de justice militaire.
Copie des jugements rendus par ces tribunaux est adressée par les parquets compétents à l’administration de l’aviation civile.
