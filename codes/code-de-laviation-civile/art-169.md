# Article 169

Aux termes des dispositions du présent code, les personnels de l’aéronautique civile sont regroupés dans les catégories de personnels spécialisés ci-après :
a) les personnels navigants professionnels ;
b) les personnels navigants non professionnels ;
c) les autres personnels aéronautiques.
