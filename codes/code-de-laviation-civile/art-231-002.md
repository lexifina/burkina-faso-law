# Article 231-2

En fonction du type d’aéronef et de la nature du vol, les documents ci-après doivent obligatoirement se trouver à bord :
‑ le certificat d’immatriculation ;
‑ le certificat de navigabilité ;
‑ le certificat acoustique ;
‑ les licences ou certificats de l’équipage ;
‑ le carnet de route ;
‑ les parties pertinentes du manuel d’exploitation ;
‑ la licence de station radio d’aéronef ;
‑ le certificat d’exploitation de l’installation radioélectrique de bord si applicable ;
‑ la liste nominative des passagers, les lieux d’embarquement et de destination ;
‑ les déclarations détaillées du fret ;
‑ le certificat d’assurance d’aéronef ;
‑ le permis d’exploitation aérienne ou une copie certifiée conforme.
Tout aéronef employé à la navigation aérienne internationale, détient un carnet de route sur lequel sont portés les renseignements relatifs à l’aéronef, à l'équipage et à chaque voyage.
