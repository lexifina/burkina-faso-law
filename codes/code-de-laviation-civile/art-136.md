# Article 136

Sans préjudice des autres dispositions du chapitre II, titre II, livre troisième du code pénal, les violences commises dans un aéronef sont punies dans les conditions prévues aux articles 318, 324 premier alinéa, 326 à 330, 333 à 335, 340 et 347 du code pénal.
