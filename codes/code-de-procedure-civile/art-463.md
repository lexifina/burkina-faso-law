# Article 463

Si une partie n'exécute pas dans les délais impartis les formalités que le juge a enjoint d'accomplir et les mesures ordonnées, la partie adverse pourra obtenir l'ordonnance de renvoi prévue à l'article 462 ; le tribunal statue sur le fond par jugement contradictoire.
