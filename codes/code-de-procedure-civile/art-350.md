# Article 350

Les juges, les membres du ministère public et les officiers de police judiciaire peuvent être pris à partie dans les cas suivants :
1°) s'il y a dol, fraude, concussion ou faute lourde professionnelle qu'on prétend avoir été commis, soit dans le cours de l'instruction, soit lors du jugement ;
2°) si la prise à partie est expressément prononcée par la loi ;
3°) si la loi déclare les juges responsables, à peine de dommages-intérêts ; 4°) s'il y a déni de justice.
