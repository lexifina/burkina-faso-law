# Article 531

En cas de solidarité ou d'indivisibilité entre plusieurs parties, c'est-à-dire lorsque, dans un cas comme dans l'autre, celles-ci peuvent être contraintes chacune à exécuter l'obligation pour le tout, l'appel formé par l'une conserve le droit d'appel des autres, sauf à ces dernières à se joindre à l'instance.
La mise en cause de tous les co-intéressés peut être ordonnée d'office par la juridiction d'appel.
