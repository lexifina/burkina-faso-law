# Article 52

Pour les actes de leur vie professionnelle, sont également domiciliés :
a) les commerçants, les industriels et les artisans au siège principal de leurs opérations ou dans les lieux où ils ont ouvert un établissement ;
b) les fonctionnaires et les officiers publics, dans le lieu où ils exercent leurs fonctions ;
c) les membres des professions libérales, dans les lieux où ils se sont installés.
