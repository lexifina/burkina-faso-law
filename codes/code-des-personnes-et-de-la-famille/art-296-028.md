# Article 296-28

Les legs sont exécutés aussitôt qu'il apparaIt que la succession est suffisante pour les payer.
Lorsque Ia succession est insuffisante pour payer tous les legs, il est observe pour le paiement l'ordre expressément stipulé par le testateur.
Faute de stipulation expresse, sont acquittés de préférence, les legs qui sont indiqués dans le testament ou dans un autre écrit émanant du défunt comme faits en rémunération de services rendus par le légataire.
Les autres legs sont réduits proportionnellement a leur valeur.
