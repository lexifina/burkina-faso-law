# Article 272-2

La tutelle s'ouvre:
1) pour les enfants nés dans le manage, lorsque les père et mere sont décédés ou se trouvent dans Fun des cas prévus a 1'article 263-11 du present code;
2) pour les enfants nés hors manage, si la filiation n'est établie a 1'égard d'aucun de leurs parents;
3) pour tous les enfants, si 1'administration légale a été convertie en tutelle;
4) dans le cas prévu a l'article 112-4 du preSent code.
