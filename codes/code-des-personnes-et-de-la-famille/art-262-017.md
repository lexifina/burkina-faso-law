# Article 262-17

L'adoption confère a 1'enfant le nom de 1'adoptant et, en cas d'adoption par les deux époux, le nom du marL Sur la demande du ou des adoptants, le tribunal peut modifier les prénoms de 1'enfant.
Si l'adoptant est une femme mariée, le tribunal peut, dans le jugement d'adoption, decider avec le consentement du man de l'adoptante, que le nom de ce dernier sera conféré a 1'adopté. Si le man est décédé ou dans l'impossibilité de manifester sa volonté, le tribunal apprécie souverainement après avoir consulté les héritiers du man ou ses successibles les plus proches.
