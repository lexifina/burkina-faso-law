# Article 221-40

Les manages coutumiers et religieux contractés antérieurement a la date d'entrée en vigueur du present code peuvent faire l'objet de transcription.
Les effets des manages coutumiers ou religieux comportant une option de monogamie sont regis par les dispositions du present code relatives au manage monogamique.
Les effets des manages coutumiers ou religieux comportant une option de polygamie sont regis par les dispositions du present code relatives au manage polygamique.
A défaut de contrat de manage, les manages comportant une option de monogamie sont regis par les règles de la communauté de biens.
