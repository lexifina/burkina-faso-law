# Article 50

La superficie pour laquelle le permis d'exploitation industrielle de grande ou de petite mine est accordé est fonction du gisement dont l'exploitation est envisagée, incluant les gisements satellites, tel qu'il est défini dans l'étude de faisabilité préparée par le titulaire du permis de recherche. Les gisements satellites nouvellement découverts font partie intégrante du permis d’exploitation.
