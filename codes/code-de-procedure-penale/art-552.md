# Article 552

Le délai entre le jour où la citation est délivrée et le jour fixé pour la comparution devant [la chambre correctionnelle du tribunal de grande instance ou le tribunal d’instance] est d'au moins :
- cinq jours si la partie citée réside dans le ressort du tribunal [...] ;
- quinze jours si elle réside dans un autre ressort du territoire ;
- deux mois dans tous les autres cas.
Par ressort du tribunal, il faut entendre le ressort du tribunal de [grande instance] [...].
