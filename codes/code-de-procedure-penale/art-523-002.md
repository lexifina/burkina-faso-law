# Article 523-2

Lorsqu'un personnel du corps des greffiers ou un officier de police judiciaire visé l'article 241-5 points 2 a 10 du present code est susceptible d'être 1'objet de poursuites pour crime ou délit commis dans Ia circonscription oü ii est territorialement competent, les dispositions de l'article 523-1 du present code sont applicables.
