# Article 530

Les dispositions de l'article 529 sont inapplicables dans les cas prévus à l'article 528. Lorsque l'agent verbalisateur ignorait la qualité de récidiviste du contrevenant, la procédure reste valable. Toutefois, le contrevenant peut être poursuivi ultérieurement devant le tribunal [d’instance].
