# Article 531-1

Le present titre s'applique, afin de garantir 1'exécution de la peine complémentaire de confiscation selon les conditions définies par le code penal, aux saisies réalisées en application du present code lorsqu'elles portent sur tout ou partie des biens d'une personne, sur un bien immobilier, surun bien ou un droit mobilier incorporel ou une créance ainsi qu'aux saisies quin'entraInent pas de dépossession du bien.
