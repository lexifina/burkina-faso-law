# Article 261-69

Les procès-verbaux d'interrogatoire et de confrontation sont établis dans les formes prévues aux articles 261-40 et 261-41 du present code.
Lorsqu'il est fait appel a un interprète, les dispositions de Farticle 261-37 du present code sont applicables.
