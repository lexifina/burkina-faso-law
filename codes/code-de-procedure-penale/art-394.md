# Article 394

Si ce jour-là il n'est point tenu d'audience, le prévenu est déféré à l'audience du premier jour ouvrable suivant, [la chambre correctionnelle] étant, au besoin, spécialement réunie. Si cette réunion est impossible, le procureur [du Faso] doit immédiatement requérir l'ouverture d'une information.
