# Article 515-35

Le procureur du Faso agissant dans les conditions prévues a l'article 515-26 du present code ou le juge d'instruction peut requérir tout agent qualiflé d'un service, d'une unite ou d'un organisme public ou tout agent qualiflé d'un exploitant de réseau ou fournisseur de services, en raison de ses compétences techniques, en vue de procéder a l'installation des dispositifs techniques mentionnés a 1'article 5 15-27 du present code.
