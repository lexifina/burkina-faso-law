# Article 323-12

Dans touS les autres cas, lTappel contre les jugements préparatoires ou interlocutoires, statuant sur les incidents et exceptions, n'est reçu, même contre les jugements rendus sur la competence, qu'après le jugement sur le fond et en même temps que 1'appel contre ledit jugement.
Cet appel ne suspend pas le cours de 1'instance.
Dans tous les cas, la partie qui a manifesté sa volonté d'interjeter appel d'un jugement dans les délais légaux conserve le droit de renouveler son appel après la decision sur le fond.
