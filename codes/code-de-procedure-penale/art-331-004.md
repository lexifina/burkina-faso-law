# Article 331-4

Lorsque les délais prescrits a l'article 33 1-3 ci-dessus n'ont pas été observes, les règles suivantes sont applicables:
1- dans le cas oü la partie citée ne se présente pas, le tribunal ordonne le renvol du dossier de sorte a ce que le délai soit respecté. Advenue cette date, ii est statue par réputé contradictoire a son égard si la partie citée ne se présente pas;
2- dans le cas oü la partie citée se présente, la citation n'est pas nulle mais le tribunal doit, sur Ia demande de Ia partie citée, ordonner le renvoi a une audience ultérieure.
Cette demande doit être présentée avant toute defense au fond, ainsi qu'il est dit a l'article 32 1-5 du preSent code.
