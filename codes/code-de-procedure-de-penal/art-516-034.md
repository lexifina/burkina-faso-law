# Article 516-34

En matière criminelle, lorsque la culpabilité du mineur est établie, la chambre criminelle spécialement composée doit :
1.
statuer sur le bénéfice de l'excuse de minorité conformément aux dispositions du code pénal ;
2.
statuer spécialement sur l'application ou la non application à l'accusé d'une peine d'emprisonnement.
