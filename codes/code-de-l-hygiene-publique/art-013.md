# Article 13

Il est interdit de déposer, de jeter ou d’enfouir les déchets de toute nature sur les voies et places publiques, sur les rives ou dans les mares, les rivières, les fleuves, les lacs, les étangs, les canaux d’évacuation des eaux pluviales et les canaux d’irrigation ou à proximité d’un point d’eau.
