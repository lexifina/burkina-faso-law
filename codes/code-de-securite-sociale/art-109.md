# Article 109

Les prestations sont suspendues :
• lorsque le titulaire ne réside pas sur le territoire national, sauf dans les cas couverts par les accords de réciprocité ou les conventions internationales ratifiées ; • lorsqu’il néglige d’utiliser les services médicaux mis à sa disposition ou n’observe pas les règles prescrites pour la vérification de l’existence de son incapacité de travail.
