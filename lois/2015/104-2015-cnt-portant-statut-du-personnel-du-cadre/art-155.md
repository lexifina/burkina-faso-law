# Article 155

Les sanctions disciplinaires suivantes peuvent être infligées au douanier dans l’ordre croissant de gravité :
- avertissement ;
- privation de motivations financières ;
- exclusion temporaire de certaines fonctions de un à quinze jours ;
- multiplication temporaire de certaines tâches ;
- blâme ;
- radiation du tableau d’avancement ;
- exclusion temporaire de certaines fonctions de seize à trente jours ;
- abaissement d’échelon ;
- rétrogradation ;
- mise à la retraite d’office ;
- révocation.
