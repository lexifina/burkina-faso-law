# Article 818

Tout officier public ou ministériel convaincu de s’être, d’une façon quelconque, rendu complice de manœuvres destinées à éluder le paiement de l’impôt est personnellement passible, indépendamment de sanctions disciplinaires, d’une amende égale à 200 % de la somme dont le Trésor public est privé avec un minimum de cent mille (100 000) francs CFA.
En cas de récidive dans les dix (10) ans d’une décision antérieure devenue définitive, l’officier public ou ministériel est frappé de destitution, sans préjudice des peines prévues par le code pénal.
