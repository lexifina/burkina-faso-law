# Article 276

Le taux de la contribution est fixé comme suit :
1) Pour les propriétés bâties :
• 0,1 % pour les immeubles à usage d’habitation ;
• 0,2 % pour les immeubles à usage autre que d’habitation.
Lorsqu’un immeuble a plusieurs usages, le taux applicable est celui fixé pour les immeubles à usage autre que d’habitation.
2) Pour les propriétés non bâties : 0,2 %.
