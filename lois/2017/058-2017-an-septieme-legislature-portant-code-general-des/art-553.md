# Article 553

Les contribuables, personnes physiques, entrant dans le champ d’application de cette contribution, ayant pour activité unique la vente de bétail, de volailles ou de peaux brutes, sont dispensés de toutes autres obligations fiscales liées à cette activité. La contribution du secteur élevage est considérée comme un minimum et un acompte déductible de l’impôt sur les bénéfices pour les autres contribuables.
