# Article 511-1

Aux termes des dispositions de la présente loi, les personnels de l’aéronautique civile sont regroupés dans les catégories de personnels spécialisés ci-après : ‑ le personnel navigant professionnel ;
‑ le personnel navigant non professionnel ;
‑ les autres personnels aéronautiques.
