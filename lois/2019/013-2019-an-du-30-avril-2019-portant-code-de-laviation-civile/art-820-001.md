# Article 820-1

Les ressources de l’Agence nationale de l’aviation civile sont constituées par : ‑ les redevances aéronautiques et extra aéronautiques ;
‑ la redevance sûreté ;
‑ les redevances de concession ;
‑ la redevance de développement aéronautique en abrégé RDA ;
‑ la dotation budgétaire de l’Etat ;
‑ les prêts, subventions, dons et legs.
Ces ressources sont exclusivement utilisées dans le domaine de l’aviation civile.
