# Article 2

[Loi 28-2004/AN du 8 septembre 2004 – Art. 1er
- les tribunaux de commerce (Loi 22-2009/AN du 12 mai 2009) . Les juridictions de l’ordre judiciaire au Burkina Faso sont :
- la Cour de cassation ;
- les Cours d’appel ;
- les tribunaux de grande instance ;
- les tribunaux d’instance ;
- les tribunaux départementaux ;
- les tribunaux d’arrondissement ;
- les tribunaux de travail ;
- les juges des enfants ;
- les tribunaux pour enfants.]
