# Article 26

Le Service des Etudes Techniques (SET) est chargé :
- d’inventorier et tenir toutes les études réalisées sur les Projets de Tambao ;
- d’assister les partenaires dans la recherche d’informations ;
- de suivre les études menées par les investisseurs ainsi que les opérations sur le terrain ;
- d’initier toutes études nécessaires complémentaires.
